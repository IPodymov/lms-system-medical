## Открытые вопросы к заказчику

1. **Объёмы данных.** Сколько студентов в крупнейшей организации? От этого зависит, нужна ли пагинация и поиск в `<select>` панели управления уже сейчас. Пока вопрос открыт, пагинация вынесена в отдельные коммиты и не блокирует визуальную миграцию.
2. **Пароли.** `AUTH_PASSWORD_VALIDATORS` в `config/settings.py` не заданы, то есть Django принимает любой пароль — и при регистрации, и при выдаче временного пароля администратором. Найдено на этапе 4.10; это не следствие редизайна, но менять политику паролей без вашего решения я не стал.
3. **Демо-данные.** В локальной базе лежат данные `manage.py seed_demo` и созданный для проверки вопрос с изображением. Если не нужны — удаляются пересозданием базы.
