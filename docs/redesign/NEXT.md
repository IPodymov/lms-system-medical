## Где всё лежит

**Ветка:** `redesign/stage-4.6-notifications` — в ней этапы 4.6–4.14.
Этапы 4.0–4.5 уже в `main`. **Остальное в `main` не смёржено.**

Полная картина: [`README.md`](README.md). Отчёт по каждому этапу:
[`03-plan.md`](03-plan.md), раздел «Ход выполнения».

```bash
cd /путь/к/lms-system-medical
git switch redesign/stage-4.6-notifications

# База локальная, в git её нет — при чистом клоне поднять заново
DJANGO_USE_SQLITE=1 .venv/bin/python manage.py migrate
DJANGO_USE_SQLITE=1 .venv/bin/python manage.py seed_demo   # пароль всех: demo12345

# Обязательно: без этого падают ВСЕ тесты (WHITENOISE_MANIFEST_STRICT)
DJANGO_USE_SQLITE=1 .venv/bin/python manage.py collectstatic --noinput

DJANGO_USE_SQLITE=1 .venv/bin/python -m pytest -q     # ожидается 124 passed
```

Локальный просмотр:

```bash
# Именно DEBUG=1: settings.py сравнивает строку с "1", поэтому DEBUG=True
# означает DEBUG=False — Django включает кеширующий загрузчик шаблонов, и
# правки шаблонов не видны до перезапуска сервера
DJANGO_USE_SQLITE=1 DEBUG=1 .venv/bin/python manage.py runserver 8000
```

Каталог компонентов: `http://127.0.0.1:8000/styleguide/` — нужен пользователь
с `is_staff` (в демо-данных это `admin@demo.local`).

## Правила, которые никуда не делись

Скилы `.claude/skills/design/SKILL.md` и `.claude/skills/frontend-traps/SKILL.md`
описывают слои CSS, критерий приёмки страницы и список ловушек, каждая из
которых уже стоила отладки. Читать перед любой правкой интерфейса.

Коротко о главном:

1. **Сверять тексты машинно, а не глазами.** Существующие строки не
   теряются:

   ```bash
   git show HEAD:templates/путь.html | grep -oE '>[^<>{%]{3,}<' \
     | sed 's/^>//;s/<$//' | sort -u
   ```

2. **`collectstatic` после добавления любого файла в `static/`.**

3. **Мёртвый CSS удаляется в том же коммите**, где страница перестала им
   пользоваться.

4. **Открыть страницу в браузере.** Дефекты этого редизайна, найденные
   только глазами: сплющенная иконка, растянутая кнопка, legend поверх
   рамки, невыровненные числа в таблице, кнопка выбора файла на 16px выше
   соседней, строка блока, не помещавшаяся на узком экране.

5. **Прогнать** `manage.py check`, `pytest`, `ruff check`, `ruff format --check`.
