# Ловушки, которые уже стоили этому проекту багов

Каждый пункт — реальный дефект, найденный в этом коде, а не теория. Симптом описан первым: по нему и ищи.

---

## 1. Число из шаблона в CSS ломается на русской локали

**Симптом.** Позиционирование или ширина не применяются, элементы схлопываются в угол или в ноль. В инспекторе видно `left: 25,0%` или `width: 50,00%`.

**Причина.** `LANGUAGE_CODE = "ru"`. Django печатает `Decimal` и `float` с **запятой**. CSS отбрасывает такое объявление целиком.

**Как правильно:**

```django
{% load l10n %}
style="--marker-x: {{ option.marker_x|unlocalize }}%"   {# дробное значение #}
style="--progress: {{ percent|floatformat:0 }}%"        {# целое: floatformat:0 достаточно #}
```

**Насколько это было серьёзно.** Из-за этого вопросы теста по изображению не работали **никогда**: все области накладывались друг на друга в левом верхнем углу. Полоса прогресса в профиле всегда показывала ноль. Ни то, ни другое не выглядело как «сломано» — выглядело как «так задумано».

**Проверка на весь проект:**

```bash
grep -rn 'style="[^"]*{{' templates/ | grep -v "unlocalize\|floatformat"
```

Вывод должен быть пустым.

## 2. Забытый collectstatic роняет всё приложение

**Симптом.** Падают **все** тесты сразу, а не один. `ValueError: Missing staticfiles manifest entry for '...'`.

**Причина.** `WHITENOISE_MANIFEST_STRICT = True`. Любой файл, на который ссылается `{% static %}`, обязан быть в манифесте.

**Правило.** Добавил файл в `static/` → сразу:

```bash
DJANGO_USE_SQLITE=1 python manage.py collectstatic --noinput
```

Массовое падение тестов после добавления CSS — почти наверняка это, а не регрессия в коде.

## 3. Глобальные селекторы легаси-слоя атакуют новые компоненты

**Симптом.** Новая кнопка не той высоты; иконка внутри неё сплющена в 2px; у поля лишний внешний отступ.

**Причина.** `components/forms.css` задаёт стили **по тегу**:

```css
button { min-height: 40px; padding: 9px 15px; background: var(--color-primary); }
input, textarea, select { display: block; width: 100%; margin-top: 5px; }
label { margin: 16px 0; }
table { background: …; border: …; }
```

Пока эти файлы живы, любой новый компонент наследует их молча. На иконочной кнопке дефект виден сразу (32px контейнер минус 30px padding = 2px под иконку), на текстовой — маскируется.

**Правило.** Новый компонент с `<button>`, `<input>`, `<label>` или `<table>` **обязан явно занулять** то, что ему навязано: `min-height`, `padding`, `margin`, `background`, `border`. С комментарием, почему это не декор.

Уйдёт вместе с легаси-слоем на этапе 4.14.

## 4. `min-width: auto` у flex-потомка растягивает страницу

**Симптом.** Горизонтальная прокрутка всей страницы. Виновник — широкая таблица или `<pre>`, **несмотря на** обёртку с `overflow-x: auto`.

**Причина.** У flex- и grid-потомка `min-width` по умолчанию равен `auto`, то есть он не может стать уже своего содержимого. Обёртка с прокруткой при этом просто растёт.

**Как правильно** — нужна **пара**, одного `min-width` мало:

```css
.wrapper { min-width: 0; max-width: 100%; overflow-x: auto; }
```

В `ui.css` это уже сделано для `.ui-stack > *`, `.ui-cluster > *` и `.ui-table-wrap`.

**Не лечи симптом** через `body { overflow-x: hidden }` — так делал прежний слой, и это прятало проблему, а не решало.

## 5. `align-items: stretch` растягивает кнопки в карточках

**Симптом.** Кнопка внутри карточки занимает всю её ширину и читается как основное действие страницы.

**Причина.** `.ui-card` — flex-колонка, потомки по умолчанию растягиваются по поперечной оси.

**Как правильно:**

```css
.карточка > .ui-btn,
.карточка > form { align-self: flex-start; }
```

Ловил дважды. Проверяй каждую карточку с кнопкой.

## 6. `<legend>` наезжает на рамку `<fieldset>`

**Симптом.** Заголовок вопроса или группы полей перечёркнут верхней границей карточки.

**Причина.** Браузер рендерит `legend` в вырезе верхней рамки `fieldset`. `display: block` этого **не отменяет**.

**Как правильно:**

```css
.legend { float: left; width: 100%; padding: 0; }
.body   { clear: both; }   /* содержимое ниже */
```

`float` здесь не украшение, а единственный способ вынуть legend из выреза. Отказываться от `fieldset`/`legend` не надо: для группы радиокнопок это правильная семантика.

## 7. Нативный `<details>` как меню требует четырёх доработок

`<details>` бесплатно даёт раскрытие мышью и клавиатурой, но **не даёт**:

1. закрытия по `Escape` с возвратом фокуса на `<summary>`;
2. закрытия при клике вне меню;
3. закрытия при уходе фокуса (проверять в `requestAnimationFrame` — на момент `focusout` у `document.activeElement` ещё старое значение);
4. закрытия соседнего меню при открытии текущего.

Всё четыре — в `static/js/navigation.js`. Прежняя реализация открывала меню по наведению и не закрывала **ничем**: с клавиатуры меню было ловушкой.

Событие `toggle` асинхронное — при программной проверке состояния добавляй задержку, иначе увидишь предыдущее значение.

## 8. Умолчание темы нельзя выводить из одного атрибута

**Симптом.** Первое нажатие на переключатель темы визуально ничего не делает.

**Причина.** Тема по умолчанию задаётся `prefers-color-scheme`, а `data-theme` появляется только после явного выбора. Если считать «нет атрибута = тёмная», то у пользователя со светлой системной темой первое нажатие «переключит» на светлую, то есть на текущую.

**Как правильно** — при отсутствии атрибута спрашивать систему (`static/js/theme_toggle.js`).

## 9. Живая область должна существовать до появления сообщения

Контейнер для тостов (`role="status"` / `role="alert"`) объявляется в `base.html` **пустым и всегда**. Если добавлять контейнер в DOM вместе с сообщением, скринридер не объявит ничего.

Роль зависит от важности: `alert` для ошибок и предупреждений (прерывает чтение), `status` для остального.

## Чек-лист отладки «стиль не применяется»

1. `collectstatic` сделан? (см. §2)
2. В инспекторе значение с запятой? (см. §1)
3. Правило перебито глобальным селектором легаси? (см. §3)
4. Файл `pages/*.css` вообще подключён на **этой** странице через `extra_css`? Класс компонента, используемый на нескольких страницах, не должен жить в CSS одной из них.
5. Класс совпадает с легаси-именем и оба слоя дерутся за него? Легаси-правило надо удалить, а не перебивать.
